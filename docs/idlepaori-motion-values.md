# IdlePaori에서 옮겨 온 연출 수치

버튼 클릭과 뽑기 결과 등장의 감각을 IdlePaori에서 그대로 가져왔다. 이 문서는 **그 수치가
어디서 왔고 무엇이 패키지에 들어왔으며 무엇이 들어오지 않았는가**를 기록한다.

## 값을 읽는 규칙 — 코드 기본값이 아니라 프리팹 값

`SlotRevealGrid`의 코드 기본값과 출시된 프리팹의 값이 다르다.

| 항목 | 코드 기본값 | `SlotResultGridPopup.prefab` |
|---|---|---|
| `_revealInterval` | 0.1 | **0.05** |
| `_accentVfxLeadSeconds` | 0.35 | **0** |
| `_playAppearOnSkippedSlots` | true | **false** |

코드만 보고 옮기면 등장 템포가 두 배 느려진다. 아래 값은 전부 프리팹 기준이다.

## 버튼 클릭

출처: `UIButtonBounceModule`. 프리팹 50곳에서 쓰이고, 45곳이 아래 값 그대로다
(나머지 5곳만 튀는 배율 1.25).

| 단계 | 배율 | 시간 | 이징 |
|---|---|---|---|
| 누름 | 0.95 | 0.085초 | OutQuad |
| 튐 | 1.15 | 0.1초 | OutQuad |
| 복귀 | 1.0 | 0.085초 | OutQuad |

`timeScale`을 무시한다(`SetUpdate(true)`) — 일시정지 중에도 버튼은 반응해야 한다.

**기준은 지금 크기가 아니라 제자리 크기다.** 뗌이 시작될 때 대상은 이미 0.95배이므로
"지금 크기의 1.15배"로 재면 1.0925배가 되고, 연타하면 크기가 조금씩 흘러내린다.
`MotionBaseScale`이 제자리 크기를 기억하는 이유가 이것이다.

**눌림 판정 영역을 스케일하지 말 것.** 레이캐스트 대상을 줄이면 축소되는 순간 판정
영역도 줄어들어, 테두리를 눌렀다 떼면 포인터가 영역 밖이라 클릭이 무효화된다. 슬롯에는
레이캐스트를 받지 않는 시각 전용 자식을 꽂는다.

→ 프리셋 `ButtonBounce` — 셋을 한 곡선에 담아 `Start` 하나로 낸다. 대부분의 버튼은 이것이면 된다.
→ 프리셋 `ButtonPressRelease` — 누르는 **동안** 눌린 채여야 하는 자리용. 트리거 `Press` / `Release`.

둘 다 슬롯은 `Visual`이다.

## 뽑기 결과 등장

출처: `SlotRevealGrid`, `ResultRevealConfigAsset`.

### 칸 하나의 연출 — 패키지에 들어왔다

| 항목 | 값 |
|---|---|
| 일반 칸 팝 | 배율 0 → 1, 0.18초, 넘치는 세기 1.7 |
| 강조 칸 슬램 | 시작 배율 → 1, 0.28초, 낙하 구간 72%, 눌림 0.12 |

넘치는 세기 1.7은 `EaseKind.OutBack`의 내장 상수(1.70158)와 사실상 같다. 강조 칸이
쓰는 3.2는 그 상수로 만들 수 없어서 `AppearCurves.OutBack`이 세기를 열어 둔다.

슬램의 낙하는 **가속한다**(`u³`). 등속으로 내려오면 그냥 줄어드는 크기일 뿐 떨어져서
박히는 것으로 보이지 않는다. `AppearCurvesTests`가 이것을 잠근다.

눌림이 사인 반주기인 것은 시작과 끝이 정확히 1이 되기 때문이다. 어느 프레임에 끊겨도
크기가 튀지 않고, 마지막 프레임을 놓쳐도 대상이 어긋난 크기로 남지 않는다.

### 등급별 — 패키지에 들어왔다

확률 **10% 이내**인 등급만 연출한다. 열 번에 한 번꼴로 나오는 것을 연출하면 연출이
연출이 아니게 된다.

| 등수 | 티어 | 시작 배율 | 머무는 시간 |
|---|---|---|---|
| 1등 | 3 | 2.2 | 0.7초 |
| 2등 | 2 | 1.5 | 0.4초 |

머무는 시간은 프리셋 그래프 안의 `Delay` 노드다. 그래야 **그래프의 길이가 곧 그 칸
차례가 끝나는 시각**이 되고, 발사하는 쪽이 초를 따로 들고 있지 않아도 된다. 밖에서
다시 저작하면 그래프를 고쳐도 타이밍이 옛 값으로 남아 조용히 어긋난다.

→ 프리셋 `SlotPopReveal`, `SlotAccentSlam_Tier2`, `SlotAccentSlam_Tier3`

### 순차 등장 — 패키지에 들어오지 않았다

여러 칸을 어긋나게 터뜨리는 오케스트레이션은 `MotionPlayer` 하나가 오브젝트 하나에
붙는 구조와 맞지 않아 가져오지 않았다. 직접 배선할 때 필요한 값은 아래가 전부다.

| 항목 | 값 | 비고 |
|---|---|---|
| 칸 등장 간격 | 0.05초 | 앞 칸의 팝(0.18초)이 끝나기를 기다리지 않는다. 그 겹침이 곧 "주르륵" 템포다 |
| 스크롤 추종 | 감쇠 계수 14 | 시간이 아니라 지수 감쇠. 목표만 바뀌므로 트윈처럼 서로 덮어쓰며 튀지 않는다 |
| 스킵 | 평범한 칸의 등장 연출을 끈다 | 켜 두면 스킵했는데도 전부 다시 터진다 |

## 패키지에 새로 들어온 것

노드를 새로 만들지 않았다. IdlePaori가 `UIScaleModule` **하나**로 바운스·누름·펄스를 전부
내고 있었고, 그 이유가 코드에 적혀 있다 — 셋을 별개 모듈로 두면 같은 `localScale`을
여럿이 동시에 만져 서로의 트윈을 덮어쓴다. **한 프로퍼티는 한 노드가 소유한다.**
그래서 `ScaleNode`를 곡선 기반으로 바꾸고 곡선 프리셋을 붙였다.

| 이름 | 자리 | 하는 일 |
|---|---|---|
| `AppearCurves` | 코어 | 세기를 지정하는 OutBack, 슬램. UnityEngine을 쓰지 않아 `dotnet test`로 검증된다 |
| `MotionCurve` | Unity | `EvaluateNormalized` — 가로축을 언제나 0~1로 편다 |
| `MotionScaleCurves` | Unity | 배율 곡선 프리셋 8개 |
| `MotionBaseScale` | Unity | 대상의 제자리 크기를 기억한다. `MotionPlayer`가 활성화될 때 잊는다 |
| `ScaleNode` | Unity | **곡선 기반으로 바뀌었다.** `To`/`Relative`/`Ease` 대신 `Curve`/`Duration` |
| `MotionCurvePresets` | 에디터 | 곡선 필드 아래의 프리셋 고르개. 곡선과 시간을 함께 넣는다 |
| `MotionPresetGenerator` | 에디터 | `Window > UI Motion > Generate Preset Graphs` |

### 곡선을 쓰는 규칙

세로축은 **제자리 크기 대비 배율**, 가로축은 진행도다.

- **1로 끝나면** 재생만으로 제자리에 돌아온다 (바운스·펄스·팝·슬램)
- **다른 값으로 끝나면** 그 배율에 머문다 (누름)
- **반복으로 쓰려면** 시작과 끝 배율이 같아야 이어지는 지점이 튀지 않는다

이징은 곡선이 겸한다. 밖에서 또 휘면 저작한 모양이 나오지 않으므로 `Ease` 필드를 두지 않았다.

### 곡선 프리셋

| 프리셋 | 시간 | 모양 |
|---|---|---|
| 버튼 뽀잉 | 0.27초 | 1 → 0.95 → 1.15 → 1 |
| 버튼 누름 | 0.085초 | 1 → 0.95, 그 배율에 머묾 |
| 버튼 뗌 | 0.185초 | 0.95 → 1.15 → 1 |
| 등장 팝 | 0.18초 | 0 → 1, 넘치는 세기 1.7 |
| 등장 팝 (강하게) | 0.28초 | 0 → 1, 넘치는 세기 3.2 |
| 슬램 1.5배 / 2.2배 | 0.28초 | 시작 배율 → 1, 낙하 72%, 눌림 0.12 |
| 펄스 | 1초 | 1 → 1.06 → 1, 반복용 |

팝과 슬램은 수식을 24점으로 구웠다. 접선은 원래 수식의 기울기를 그대로 준다 —
Unity의 자동 접선은 이웃 키만 보므로 슬램처럼 치우친 곡선에서 없던 출렁임을 만든다.
24점인 것은 **고칠 수 있는 곡선**으로 남기기 위해서다. 촘촘하게 구우면 편집기가 키
무더기가 되어 손댈 수 없다.

### 프리셋 그래프

`ButtonBounce` · `ButtonPressRelease` · `SlotPopReveal` ·
`SlotAccentSlam_Tier2` · `SlotAccentSlam_Tier3` · `AttentionPulse`

### 가져오지 않은 것 — 복귀 트윈

IdlePaori의 `UIScaleModule`은 `Stop()`에서 **지금 배율에서 1로** `OutBack`을 타고
0.12초에 걸쳐 돌아온다. 곡선을 거꾸로 훑지 않는다 — 곡선은 "재생의 모양"이고 복귀는
"놓았을 때의 모양"이라 서로 다르기 때문이다.

이 패키지는 취소될 때 `Remember`가 등록한 값으로 **즉시** 되돌린다. 그것이 원상 복구
규약이고, 여기만 예외로 두면 규약이 규약이 아니게 된다. 대신 그래프에서 뗌을 별도
트리거로 두면 같은 결과가 나오고 **캔버스에 보인다** — `ButtonPressRelease` 프리셋이 그것이다.

### `MotionBaseScale`의 함정 하나

연출이 이미 대상의 크기를 바꿔 놓은 뒤에 처음 물으면 **그 크기가 제자리 크기로 굽힌다.**
같은 대상에 크기를 만지는 연출을 둘 이상 겹치지 말 것. `ScaleNode` 하나가 그 대상의
`localScale`을 소유해야 한다.
